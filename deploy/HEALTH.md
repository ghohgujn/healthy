# Шаги и активные калории из «Здоровья»

Браузер не может читать Apple Health или Health Connect напрямую, поэтому данные присылает сам телефон на личный адрес пользователя:

```
POST https://<ваш-сайт>/api/health/ingest?t=<личный-ключ>
Content-Type: application/json
```

Личный адрес с ключом виден в приложении: Профиль → «Здоровье и браслеты» → «Подключить». Ключ можно сменить там же.

## Формат
Сервер принимает любой JSON и сам находит в нём шаги и активные калории:
- простой: `{"date":"2026-10-20","steps":8421,"active_kcal":412}`
- массивы записей с датой: `{"steps":[{"startTime":"2026-10-20T08:00:00Z","count":3000}], "activeCaloriesBurned":[{"startTime":"…","energy":{"inKilocalories":150}}]}`
- если даты нет — берётся сегодняшняя (или `?date=YYYY-MM-DD`).

Повторная отправка за тот же день перезаписывает значения, поэтому отправлять можно хоть каждый час.

## iPhone — готовая «Быстрая команда» (для пользователей: 2 нажатия)

Пользователь видит в приложении 3 шага: **«Добавить»** (личный адрес копируется сам, «Команды» спрашивают его при добавлении — «Вставить»), **«Запустить»** (один раз разрешить доступ к «Здоровью»), по желанию — автоматизация. Потом — кнопка «Обновить» в профиле и «Из «Здоровья»» рядом с шагами.

Для этого команду один раз собирает владелец сервера и публикует ссылкой iCloud:

1. «Команды» → **+** → имя ровно **Healthy Fit**.
2. **Текст** — впишите `вставьте адрес` (это поле заменится адресом пользователя).
3. **Найти образцы здоровья** → тип «Шаги», «Дата начала» — «Сегодня» → **Вычислить статистику** → «Сумма».
4. Ещё раз **Найти образцы здоровья** → «Активная энергия», «Сегодня» → **Вычислить статистику** → «Сумма».
5. **Получить содержимое URL** → URL: переменная «Текст»; «Показать больше»: метод **POST**, тело **JSON**, поля `steps` (Число) = первая «Статистика», `active_kcal` (Число) = вторая.
6. Запустите один раз сами — проверьте, что приходит `{"ok":true,...}`.
7. Нажмите на название команды → **«Настроить»** → «Вопросы при импорте» → **«Добавить вопрос»** → выберите действие «Текст» → вопрос: «Вставьте ваш адрес Healthy Fit (он уже скопирован)».
8. «Поделиться» → **«Скопировать ссылку iCloud»**.
9. Вставьте ссылку в `public/config.js` → `healthShortcut: 'https://www.icloud.com/shortcuts/…'` и залейте в GitHub (или пришлите ссылку — добавлю).

Пока ссылки нет, приложение показывает ручную инструкцию сборки.

## Android — Health Connect
1. Шагомер (Google Fit, Samsung Health, Mi Fitness, Zepp…) пишет в Health Connect.
2. Приложение **HC Webhook** (github.com/mcnaveen/health-connect-webhook): доступ к «Шагам» и «Активным калориям», Webhook URL — адрес из приложения, интервал 1–3 часа.

## Как учитывается
За день к норме прибавляется большее из двух: активные калории из «Здоровья» или сумма отмеченных тренировок + шаги. Так тренировка, записанная часами, не считается дважды.
