# Healthy Fit — КБЖУ по фото

Сфотографировал тарелку → граммы и КБЖУ → «Добавить в дневник». Плюс вода, календарь тренировок, профиль с расчётом нормы, стрик, друзья и мессенджер (текст, еда, голосовые, кружки), шаги и калории из «Здоровья».

## Структура
```
public/            сайт (без сборки, чистый HTML/CSS/JS)
  index.html       разметка: вкладки Сегодня / Активность / Профиль, камера, шторки
  app.js           логика: дневник, камера, вода, календарь, профиль, стрик, графики
  social.js        аккаунт, поиск и друзья, огонёк дружбы, чаты, голосовые и кружки (кнопка как в Telegram), «поделиться», «Здоровье», облачная копия
  onboarding.js    онбординг при первом запуске (аккаунт → цель → параметры → активность → норма) и скрытая панель разработчика
  calc.js          формулы: норма (Миффлин–Сан Жеор / Каннингем), цели, MET-тренировки, шаги, тренд веса
  app.css, tokens.css   стили и дизайн-токены (светлая/тёмная тема)
  manifest.webmanifest, icon-*.png   установка на экран «Домой»
server/server.js   Node 22 без внешних зависимостей: сайт, /api/analyze → ProxyAPI (ключ только на сервере),
                   аккаунты (scrypt + httpOnly-cookie), друзья, сообщения, медиа, приём данных «Здоровья», SQLite
server/prompt.txt  промпт для нейросети
deploy/HEALTH.md   как подключить iPhone «Быстрые команды» и Android Health Connect
demo/              только для превью без сервера (заглушка API с демо-друзьями); в public/ не подключается
deploy/install.sh  установка на Ubuntu VPS: Node, Caddy (HTTPS), systemd, автообновление из GitHub
```

## Установка на сервер
В консоли VPS (Ubuntu 24.04) под root:
```
curl -fsSL https://raw.githubusercontent.com/ghohgujn/healthy/main/deploy/install.sh | bash
```
Скрипт спросит ключ ProxyAPI. Сайт будет на `https://<ip-через-дефисы>.sslip.io`. Каждые 2 минуты сервер подтягивает новые коммиты из `main`.

## Данные
Дневник, вода, тренировки, вес и профиль хранятся в браузере телефона (localStorage) и, если пользователь вошёл, копируются на сервер. Аккаунты, друзья, сообщения и медиа — в `/var/lib/healthy` (SQLite + файлы), ночной бэкап в `/var/backups/healthy`. Фото уходит в нейросеть только для распознавания, на сервере не сохраняется.

## Скрытая панель разработчика
Профиль → 5 быстрых нажатий на заголовок «О себе». Там выбор нейросети, состояние данных, повтор онбординга, проверка сервера.

## Огонёк дружбы
День засчитывается, если вы оба написали друг другу. 3+ дня подряд — огонёк горит. Пропустили день — гаснет; восстановить можно один раз на пару. Часовой пояс дней — переменная `APP_TZ` в `/etc/healthy.env` (по умолчанию Europe/Moscow).

## Защита баланса нейросети

- `RATE_LIMIT` (по умолчанию 30) — распознаваний за 10 минут с одного IP и с одного аккаунта.
- `AI_DAILY_LIMIT` (по умолчанию 1500) — общий потолок распознаваний в сутки на весь сервер. Меняется в `/etc/healthy.env`, затем `systemctl restart healthy`.
- IP берётся из последнего адреса `X-Forwarded-For`, который дописывает Caddy, поэтому подделать его нельзя.
